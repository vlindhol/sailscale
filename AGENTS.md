# Repo layout

1. Specs are in the specs/ folder. They are numbered documents, each document representing some larger unit of work. Specs are written as _forward-looking_, i.e. they are written before an implementation is started.
2. Information about the codebase and project in its current state lives in the corpus/ folder. The idea of a corpus is to encapsulate all of the behavior of the project on a high level, preferably understandable by a product manager or similar role.
